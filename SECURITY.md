# Security Policy

## Supported versions

The project is currently in beta. Security and data-integrity fixes are provided for the latest beta release only.

## Reporting a vulnerability

Please do not include confidential documents, production data, credentials, tokens, personal paths, or screenshots containing sensitive information in public issues.

For suspected security or document-integrity problems, open a minimal GitHub issue that describes the affected version and reproduction steps using synthetic data only. If the report itself would disclose sensitive information, contact the repository maintainer privately before posting details publicly.

## Local-data model

WPS Word Formatter is designed for local/offline use. It does not require a cloud API or external document-upload service. Users should still review generated diagnostic logs before sharing them publicly because environment paths and document metadata may be present.
